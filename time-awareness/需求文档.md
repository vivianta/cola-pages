# 时间知觉 — 产品需求文档

## 概述

时间知觉是一个个人时间追踪与精力管理工具。用户通过**计划**和**记录**两个模式，追踪每天的时间去向，对比计划与实际执行的差距，逐步改善时间使用习惯。

网页应用，电脑和手机均可通过浏览器访问。数据通过 Google Sheets 在设备间自动同步。

---

## 1. 顶部日期与同步状态

- 页面顶部显示当天日期（年/月/日）和星期
- 日期下方显示同步状态点：
  - **绿点**：已同步
  - **黄点闪烁**：同步中
  - **红点**：同步失败
  - **灰点**：未设置同步

---

## 2. 模式切换

页面顶部有两个模式按钮：**计划** / **记录**。点击切换模式，按钮高亮显示当前模式。

两个模式各自独立运行，切换模式不会中断另一个模式的活跃任务。

---

## 3. 计划模式

### 3.1 分类

5 个分类，用大按钮展示：

| 图标 | 分类名称 |
|---|---|
| 💼 | 工作/学习 |
| 🏠 | 家务 |
| 🏃 | 锻炼 |
| 🔋 | 充电 |
| 📱 | 消遣 |

### 3.2 开始计划

- 点击任一分类按钮，开始一个计划，时长固定 **1 小时**
- 状态区域显示：当前计划的分类、开始时间 – 结束时间、剩余时间、进度条
- 计划进行中，该分类按钮高亮

### 3.3 切换计划

- 点击另一个分类，当前计划自动截断（提前结束），新计划立即开始
- 被截断的计划以实际结束时间为准

### 3.4 结束计划

- 点击「结束当前计划」，计划在点击时刻结束
- 1 小时到后计划自动结束（不再显示为活跃）

### 3.5 计划不可编辑

- 计划条目创建后**不能修改或删除**（包括时间、分类）
- 时间线中计划条目标注"计划"徽章，右侧显示"不可编辑"

---

## 4. 记录模式

### 4.1 分类

6 个分类，比计划多一个：

| 图标 | 分类名称 |
|---|---|
| 💼 | 工作/学习 |
| 🏠 | 家务 |
| 🏃 | 锻炼 |
| 🔋 | 充电 |
| 📱 | 消遣 |
| ❓ | 未记录 |

- "未记录"用于事后编辑时，标记无明确分类的时段
- 如果某个分类当天已有记录时长，按钮下方显示累计时间

### 4.2 开始记录

- 点击任一分类，开始计时，状态区域显示数字计时器（HH:MM:SS）
- 正在计时的分类按钮高亮

### 4.3 切换记录

- 点击另一个分类，当前记录自动结束，新记录开始

### 4.4 停止记录

- 点击「停止记录」，当前记录在点击时刻结束

### 4.5 记录可编辑

- 时间线中记录条目右侧有编辑（✏️）和删除（🗑）按钮
- 编辑弹窗可修改：分类、开始时间、结束时间
- 结束时间不能早于或等于开始时间

### 4.6 消遣提醒

- 当记录模式下的**消遣**分类连续计时超过 **20 分钟**时：
  - 消遣按钮开始**闪烁变色**（红粉色脉冲动效）
  - 播放一段**温和的双音铃声**
- 提醒只在记录模式下生效，计划模式不触发
- 同一次消遣会话只提醒一次

---

## 5. 时间线

时间线标签页按时间顺序显示今天的所有**计划**和**记录**条目，混排展示。

每条目包含：
- **类型徽章**：计划（蓝色"计划"标签）或记录（绿色"记录"标签）
- **时间段**：开始时间 换行 结束时间（进行中显示"进行中"）
- **分类**：图标 + 名称
- **时长**：x 小时 x 分 / x 分钟 / 计时中…

视觉区分：
- 计划条目：**虚线**左边框
- 记录条目：**实线**左边框

---

## 6. 统计

统计标签页展示今日数据：

### 6.1 今日计划（如有数据）

卡片网格，每个分类显示：图标、名称、时长、占比百分比。

### 6.2 今日记录（如有数据）

同上，包含"未记录"分类（时长为 0 时不显示）。

下方有横向条形图，直观展示各分类时长占比。

### 6.3 计划 vs 实际对比（两者均有数据时）

每个分类两行条形图：
- 上方浅色条 = 计划时长
- 下方深色条 = 实际记录时长
- 右侧显示：计划时长 / 实际时长

---

## 7. 设置

### 7.1 云同步

- 输入 Google Apps Script 网页应用 URL，点保存即可开启同步
- 已连接时显示「立即同步」和「断开」按钮
- 未连接时显示输入框和部署说明

### 7.2 数据管理

- **导出**：下载 JSON 文件
- **导入**：选择 JSON 文件，合并到现有数据（按 id 去重）
- **清空**：确认后删除全部数据（含云端）

---

## 8. 跨设备同步

- 同一 Google 账号下的多台设备，设置相同同步 URL 后数据自动同步
- 打开页面时自动从云端拉取最新数据
- 数据变更后自动推送到云端（3 秒防抖 + 关闭/切走页面时立即推送）
- 另一台设备的活跃状态（正在进行的计划/记录）在刷新页面后自动恢复

---

## 9. 数据持久化

- 所有数据默认存储在浏览器本地（localStorage）
- 设置同步后，数据同时存储在 Google Sheets 的 A1 单元格中
- 导出文件格式：`{"sessions": [...]}`，每条 session 包含 id、type（plan/record）、category、start、end
- 关闭浏览器后重新打开，如果之前有未结束的记录或未到期的计划，自动恢复

---

## 10. 响应式

- 页面在手机和电脑浏览器上均可正常使用
- 分类按钮在窄屏上自动适配大小
